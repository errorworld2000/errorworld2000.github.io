细节实现

发表于 2025-04-20 更新于 2025-07-19 分类于 gameframework 阅读次数： Valine：

ReferencePool

IReference

被引用的对象需实现IReference接口（包括一个Clear函数），当对象被回收时调用，恢复初始状态，以便下次使用。

ReferenceCollection

代表一种类型的引用池，位于ReferencePool内部

ReferenceInfo

获取引用池的状态计数，相较ReferenceCollection少了m_References

ReferencePool

静态类，管理所有类型的引用池

具体操作时先根据类型（为Type时先要对类型进行检查）获取对应的ReferenceCollection，再进行其他操作。

Fsm

FsmState< T >

状态机状态的抽象类，包括状态初始化，状态更新等等

IFsm< T >

状态机的接口

FsmBase

状态机的抽象类

Fsm< T >

一个状态机，包括所有状态类以及当前数据

IFsmManager

接口，管理所有状态机

Procedure

ProcedureManager

特殊的Fsm，也交给FsmManager管理

Setting

只需根据ISettingHelper创建设置辅助器即可完成，ISettingManager用于使用

module

只暴露接口，具体实现在只在程序集可见，使用getmodule进行实例化

this GameObject gameObject：

  • this：表示这是一个扩展方法，并且该方法是对 GameObject 类型的扩展。
  • GameObject：表示要扩展的类型（这里是 Unity 的 GameObject 类）。
  • gameObject：是方法的参数，表示调用该方法时传入的目标对象。

DataProvider

ReadData

m_ResourceManager.LoadAsset加载资产，并把一个回调函数传进去，回调函数激发provider的事件

​ m_UIManager.CloseUIFormComplete += OnCloseUIFormComplete;

在gameframework提供接口，在runtime里面将不同模块结合起来
